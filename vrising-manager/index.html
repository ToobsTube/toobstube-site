Run your V Rising server from one window.

Start, stop and restart your dedicated server, warn players before it goes down, back up the world, and change settings without digging through config files. Every stop saves the world first, so nobody loses progress.

What it does
Features
New in 1.1
Saves on every stop
Stopping the server shuts it down properly, so V Rising saves the world first and players log back in where they left. Scheduled and daily restarts work the same way.
Restarts
Scheduled & daily restarts
Restart in a set number of minutes, or every day at a set time. Players get in-game warnings at 10, 5, 2 and 1 minute out.
Backups
World backups
Back up the save on demand or on a schedule, to any drive or a cloud-synced folder like OneDrive or Google Drive. Choose how many to keep.
New in 1.1
Connection Check
One click tells you whether the server is answering, how fast it answers from outside, and whether Steam's server list has it. Each result says what to fix.
Settings
Game settings, no config files
Player limits, PvP, day and night length, XP and resource rates, castle decay and more, with sliders and plain-English tooltips.
Setup
Install & update with SteamCMD
Download the dedicated server from scratch or update an existing one from inside the app. It stops the server safely first.
Admin
Players & admin tools
See who's been on, make admins, kick or ban, and send announcements or RCON commands.
Profiles
More than one server
Give each server its own profile, or run one copy of the manager per server at the same time.

Getting started
Install
  1. Download VRising.Server.Manager.exe from the latest release on GitHub.
  2. Put it in a folder of its own, for example on your desktop. It saves its settings next to itself, so keep it in the same place when you update.
  3. Run it. If Windows shows "Windows protected your PC", click More info, then Run anyway.
  4. Point it at your server on the Setup tab, or let it download a fresh server with SteamCMD.
About that Windows warning
The app isn't code-signed, so Windows SmartScreen doesn't recognize it and warns you before the first run. That's normal for free community tools. The full source code is on GitHub if you'd like to check it, or run the Python script instead of the .exe.
In-game warnings need RCON
Restart warnings are sent to players through RCON. Turn it on in your server's ServerHostSettings.json, then enter the same password in the manager. How to enable RCON.
Can't see your own server?
If you play from the same house as the server, many home routers make it look slow or hide it from the list. Loosen the server list's Latency filter, or use Direct Connect to the server PC's local IP with LAN Server ticked. Players outside your home aren't affected.
